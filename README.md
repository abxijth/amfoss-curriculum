# Anveshan Curriculum

## Overview

The Anveshan Curriculum is a structured learning path designed to help new amFOSS members get started with development through hands-on, practical tasks. It focuses on building a strong foundation across multiple domains while allowing flexibility to explore individual interests.

## What I Learned

* Core concepts across major development domains
* Practical problem-solving through real-world style tasks
* Learning by building rather than passive study

## Experience

The curriculum encouraged consistency, exploration, and independent thinking. Each task helped strengthen my understanding of software engineering fundamentals while giving me the freedom to experiment and grow.

## Completion

This repository represents the successful completion of the Anveshan Curriculum.
